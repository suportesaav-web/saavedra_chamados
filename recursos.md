# 📚 Guia de Recursos e Materiais de Estudo

Este documento centraliza referências oficiais, documentações, ferramentas e tutoriais organizados pelas 4 semanas do Plano de Estudos de Automação e DevOps.

---

## 🛠️ Semana 1: Fundamentos de Python e Versionamento

### 📚 Documentação & Tutoriais
- **[Documentação Oficial do Python 3 (PT-BR)](https://docs.python.org/pt-br/3/tutorial/)** — Tutorial oficial cobrindo a sintaxe e estruturas básicas.
- **[Pro Git Book (Gratuito)](https://git-scm.com/book/pt-br/v2)** — Livro oficial de referência do Git traduzido em português.
- **[Git Documentation - Reference](https://git-scm.com/docs)** — Manual com a lista completa dos comandos Git.

### 🔧 Ferramentas & Setup
- **[VS Code](https://code.visualstudio.com/)** — Editor recomendado.
  - Extension: *Python (Microsoft)*
  - Extension: *GitGraph* ou *GitLens*
- **[GitHub Guides](https://skills.github.com/)** — Cursos práticos e interativos diretamente no GitHub.

---

## 🌐 Semana 2: Integração de Dados e Conceitos de Rede

### 📚 Documentação & Tutoriais
- **[W3Schools SQL Tutorial](https://www.w3schools.com/sql/)** — Guia interativo rápido para aprender comandos `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
- **[MDN Web Docs - Visão Geral do HTTP](https://developer.mozilla.org/pt-BR/docs/Web/HTTP/Overview)** — Explicação sobre mensagens, métodos e status HTTP.
- **[JSON.org Spec](https://www.json.org/json-pt.html)** — Definição do formato leve de troca de dados JSON.
- **[Python `requests` Library Docs](https://requests.readthedocs.io/en/latest/)** — Guia oficial da biblioteca standard de requisições HTTP em Python.

### 🔧 Ferramentas & Testes
- **[Postman](https://www.postman.com/)** — Plataforma API client para testar e documentar requisições.
- **[curl Command Line Utility](https://curl.se/docs/manpage.html)** — Manual de uso do utilitário cURL para chamadas via terminal.
- **[JSONPlaceholder](https://jsonplaceholder.typicode.com/)** — REST API fake pública para testes de consumo HTTP.

---

## ⚡ Semana 3: Primeiro Framework Web (FastAPI ou Flask)

### 📚 Documentação & Tutoriais
- **[FastAPI Official Tutorial (PT-BR)](https://fastapi.tiangolo.com/pt/)** — Uma das melhores documentações com tutoriais interativos do básico ao avançado.
- **[Flask Documentation](https://flask.palletsprojects.com/)** — Documentação do micro-framework tradicional em Python.
- **[Pydantic Docs](https://docs.pydantic.dev/)** — Validação de dados e gestão de configurações com tipos nativos do Python.
- **[SQLAlchemy ORM Documentation](https://docs.sqlalchemy.org/)** — Toolkit SQL e Object Relational Mapper para Python.

### 🔧 Ferramentas & Testes
- **[Uvicorn ASGI Server](https://www.uvicorn.org/)** — Servidor web lightning-fast para executar aplicações FastAPI.
- **Swagger UI / OpenAPI** — Gerado automaticamente acessando a rota `/docs` em aplicações FastAPI.

---

## 🤖 Semana 4: Consolidação, Automação e DevOps

### 📚 Documentação & Tutoriais
- **[Python `logging` Module](https://docs.python.org/3/library/logging.html)** — Como implementar sistemas de log padronizados em scripts de automação.
- **[Python `subprocess` Module](https://docs.python.org/3/library/subprocess.html)** — Execução de comandos do sistema operacional via Python.
- **[python-dotenv Docs](https://pypi.org/project/python-dotenv/)** — Leitura de variáveis de ambiente a partir de arquivos `.env`.
- **[4Linux DevOps & Automation Roadmap](https://www.4linux.com.br/)** — Conceitos de automação, infraestrutura como código (IaC) e cultura DevOps.

### 🔧 Ferramentas & Bibliotecas Utilitárias
- **[Schedule (Python)](https://schedule.readthedocs.io/)** — Biblioteca simples para agendamento de tarefas recorrentes em Python.
- **[Rich (Python UI CLI)](https://rich.readthedocs.io/)** — Biblioteca para formatação de saídas ricas no terminal (tabelas, barras de progresso, cores).
